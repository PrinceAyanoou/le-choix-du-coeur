# Le Choix du Cœur

Un petit quiz romantique de couple, avec 12 questions sur vos souvenirs et vos
façons de vous aimer, un portrait adapté aux réponses, un message personnel et
un mini-défi à faire à deux.

## Lancer le site

```bash
npm install
npm run dev
```

Ouvrez ensuite [http://localhost:3000](http://localhost:3000).

## Vérifier le projet

```bash
npm test
npm run build
```

Les réponses sont utilisées uniquement pour composer le résultat et ne sont
pas transmises à un serveur. Le prénom est facultatif.
